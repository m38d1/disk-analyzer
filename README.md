# دیسک‌کاو — نسخهٔ دمو

تحلیل حافظهٔ داخلی مک در یک صفحهٔ تک‌فایلی: درخت تری‌مپ پوشه‌ها، نمودار دسته‌ها، سنگین‌ترین فایل‌ها، کاوشگر و پیشنهادهای حذف با درجهٔ ریسک.

این نسخهٔ **نمایشی** است و دادهٔ نمونه دارد؛ دکمهٔ اسکن در آن غیرفعال است. نسخهٔ محلی همان صفحه، دیسک واقعی را می‌خواند و همان‌جا به‌روز می‌کند.

- بدون وابستگی خارجی: فونت وزیرمتن و داده داخل خود فایل هستند
- نصب‌پذیر به‌صورت وب‌اپ (manifest + service worker)
- فرمان‌های پیشنهادی فقط کپی می‌شوند؛ صفحه هیچ‌چیز را اجرا یا حذف نمی‌کند
